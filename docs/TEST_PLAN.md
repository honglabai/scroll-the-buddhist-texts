# TEST_PLAN — 검증 및 출시 게이트 기준

## 1. 테스트 계층
- **정적 검증**: `npm run typecheck`, `npm run lint`
- **콘텐츠/권리 검증**: `npm run validate:content` (미승인/권리 누락 콘텐츠 빌드 차단 확인)
- **단위 테스트 (Unit)**: 도메인 규칙, 권리 필터링, NFC 정규화, 검색 매칭, 읽기 계획 자정 경계 및 중복 방지, AI RAG 인용 검증 및 프롬프트 인젝션 방어, 50+ AI 평가 질의셋
- **통합 테스트 (Integration)**: Repository CRUD, 마이그레이션 보존, 번역 전환 시 단락 유지, 북마크/메모 영구 저장, 권리별 공유 제한, 미검수 해설 비노출
- **성능/회귀 테스트 (E2E/Stress)**: 10,000개 합성 단락에서 500회 이동 누락/충돌 0건, 장문 분할/미절단, 데이터 삭제 정합성

## 2. 출시 게이트 (Release Gates)
- [ ] 승인된 경문 단락 ID/순서 100% 검증, 중복/누락 0
- [ ] 비행기 모드(오프라인)에서 읽기/검색/저장/메모 정상 작동
- [ ] 재시작/번역 전환 시 읽기 위치 복원
- [ ] 접근성: 5단계 글씨(18~34sp), 48dp 터치, 대비 4.5:1+, 모션 감소, 스크린리더 라벨
- [ ] 개인정보: 일지/읽기 기록 로컬 비공개, 로그/AI 요청에 민감정보 미포함
- [ ] AI: 검증되지 않은 인용 0, 근거 부족 시 답변 제한, AI 없이 일반 읽기 정상
