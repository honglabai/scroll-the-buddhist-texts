# PRD — Scroll the Buddhist Texts (마음스크롤 / Dharma Scroll)

## 1. 제품 개요
- **프로젝트명**: Scroll the Buddhist Texts
- **브랜드 후보**: 마음스크롤 : 하루 한 구절 불경 / Dharma Scroll (정식 상표 검토 전 확정하지 않음)
- **슬로건**: 스크롤할수록 마음이 맑아지는 시간
- **대상**: 한국어 사용자 우선, Android 실기기 우선, iOS 확장 및 웹 어댑터 지원
- **핵심 가치**: 비회원·무료·오프라인 기본, 자발적 읽기 습관 형성(`SCROLL -> UNDERSTAND -> REFLECT -> PRACTICE -> RETURN`)
